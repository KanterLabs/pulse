# Pulse

Pulse is planned as a Fedora GNOME command center for the official Spotify desktop client.

The repository is currently in the implementation-planning stage. Start with the [Fedora laptop implementation plan](docs/FEDORA_IMPLEMENTATION_PLAN.md).

The initial delivery target is a native per-user GNOME Shell extension plus Rust daemon that can be copied as one folder from the development VM and installed without assuming a fixed source path.
